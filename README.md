# 💬 ChatGPT로 경제 데이터 분석하기

## 🎯 스터디 목적

- 이 스터디는 ChatGPT와 파이썬을 활용하여 경제 데이터를 분석하는 방법을 학습하는 것을 목적으로 합니다. 
학생들은 다양한 데이터 수집 기법, 전처리 방법, 탐색적 데이터 분석, 시계열 분석, 예측 모델링, 금융 데이터 분석, 정책 분석, 리스크 분석, 자연어 처리 등의 기술을 습득하게 됩니다. 
또한, ChatGPT를 활용한 데이터 분석 자동화 및 실시간 분석 방법도 학습하게 됩니다. 

- 👨‍🏫 챕터별 브랜치에 접속하여 작업을 진행합니다. 로컬에서 브랜치를 불러와 작업하는 방법은 아래와 같습니다.
- <브랜치 로컬에 가져오기>
- git fetch origin <브랜치 이름>
- git checkout <브랜치 이름>
- <작업 후 변경사항 푸시>
- git commit -m "변경사항 메시지"
- git push origin <브랜치 이름>

- 🗣️ 양식은 md파일 또는 qmd파일로 작성합니다. 코드는 google colab에서 실행될 수 있도록 작성합니다.

- 📝 실습에 사용되는 파일은 github data폴더에 올려두고 해당 위치를 참조하여 코드가 실행될 수 있도록 합니다.

- 💻 브랜치 푸쉬 및 머지 작업은 1월까지 계속 진행합니다.
